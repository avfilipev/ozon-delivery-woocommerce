# Ozon Доставка для WooCommerce

Интеграция API Ozon Доставки в WooCommerce: расчёт стоимости, выбор пункта
выдачи на чекауте, передача заказа в Ozon, статусы отправлений, отмены и
возвраты.

## Состояние

Фазы 0–6 плана готовы и проверены в живом WordPress + WooCommerce. Подробный
отчёт по каждой фазе — в [docs/PROGRESS.md](docs/PROGRESS.md).

**Ни один запрос к боевому API Ozon ещё не выполнялся**: нет ключей. Всё
проверено юнит-тестами (600 тестов), статическим анализом и прогоном в
wp-env с подменой HTTP-слоя.

## Быстрый старт

```bash
composer install
npm install
npx wp-env start
```

Затем в админке: WooCommerce → Настройки → Ozon Доставка → заполнить ключи →
«Проверить подключение» → «Обновить каталог».

Пока не убедитесь, что всё работает, оставьте включённым **dry-run**: запросы
на запись будут логироваться, но не отправляться. Песочницы у Ozon нет,
боевой контур один.

## Разработка

```bash
composer test      # PHPUnit
composer lint      # PHPCS, WordPress Coding Standards
composer analyse   # PHPStan, уровень 6
```

Правила работы над проектом — в [CLAUDE.md](CLAUDE.md), там же описаны две
ловушки, которые роняют тесты молча, и опасные команды wp-env.

План, архитектура и фазы — в [docs/PLAN.md](docs/PLAN.md).
Справочник по API — в [docs/API.md](docs/API.md).

## Что не сделано

* **Курьерская доставка.** `order/create` требует координаты получателя, а
  WooCommerce их не хранит — нужен геокодер, то есть ещё один внешний сервис.
* **Карта ПВЗ на чекауте.** Сейчас список с поиском по городу.
* **Блочный чекаут.** Плагин явно объявляет несовместимость с
  `cart_checkout_blocks`; совместимость с HPOS заявлена.
* **Три схемы ответов не подтверждены живьём** — см. `tests/Fixtures/README.md`.
