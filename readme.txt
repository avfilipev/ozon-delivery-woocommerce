Доставка до пунктов выдачи Ozon в WooCommerce: расчёт стоимости, выбор ПВЗ на чекауте, передача заказа и статусы.

== Description ==

Плагин подключает WooCommerce к API Ozon Доставки: покупатель выбирает пункт выдачи прямо на чекауте, стоимость и срок приходят из Ozon по составу корзины, заказ передаётся в Ozon, а статусы отправления возвращаются в заказ.

**Что умеет**

* Метод доставки до пункта выдачи Ozon со стоимостью и сроком из `order/checkout`.
* Свой каталог ПВЗ: фоновая синхронизация, поиск по городу на чекауте, отсев точек, которые не примут отправление по весу, габаритам или объявленной стоимости.
* Передача заказа в Ozon с ключом идемпотентности — повтор не создаёт второе отправление.
* Подтверждение к отгрузке, этикетка, отмена и опрос статусов.
* Возвраты: список, статусы и штрихкод получения.
* Режим dry-run: запросы на запись логируются, но не отправляются.
* Команды WP-CLI: `wp ozon token`, `wp ozon points sync`, `wp ozon checkout`, `wp ozon push`, `wp ozon status`, `wp ozon raw`.

**Что нужно для работы**

Ключи частного приложения из личного кабинета Ozon Доставки: Настройки → Управление частными приложениями. Там же создаётся метод доставки, номер его штрихкода — это `Shipment Method ID` в настройках плагина.

== External services ==

Плагин передаёт данные в API Ozon Доставки (`api-delivery.ozon.ru`) и получает токен доступа на `xapi.ozon.ru`. Без этого доставка Ozon работать не может.

**Что и когда отправляется**

* При расчёте доставки: номер телефона покупателя, вес и габариты заказа, объявленная стоимость, идентификатор выбранного пункта выдачи.
* При передаче заказа: дополнительно имя покупателя и номер заказа.
* При проверке доступности доставки: номер телефона покупателя.

Условия использования Ozon: https://docs.ozon.ru/api/ozon-delivery/

Персональные данные покупателя (телефон и имя) передаются третьей стороне — Ozon. Упомяните это в политике конфиденциальности магазина и получите согласие покупателя на чекауте.

== Installation ==

1. Установите и активируйте плагин.
2. WooCommerce → Настройки → Ozon Доставка: укажите Client ID, Client Secret, Scope и Shipment Method ID.
3. Нажмите «Проверить подключение», затем «Обновить каталог».
4. WooCommerce → Настройки → Доставка: добавьте метод «Ozon Доставка — пункт выдачи» в нужную зону.

Пока не убедитесь, что всё работает, оставьте включённым режим dry-run: заказы в Ozon уходить не будут.

== Frequently Asked Questions ==

= Почему метод доставки не появляется на чекауте? =

Проверьте по очереди: заданы ли ключи и Shipment Method ID, загружен ли каталог ПВЗ, добавлен ли метод в зону доставки, выбран ли покупателем пункт выдачи и указан ли телефон. Причина отказа показывается отдельной строкой под таблицей доставки, а подробности пишутся в WooCommerce → Статус → Журналы, источник `ozon-delivery`.

= Доставка доступна не всем покупателям =

Так и есть: Ozon Доставка работает только для покупателей, зарегистрированных на Ozon. Плагин проверяет это по номеру телефона.

= Поддерживается ли курьерская доставка? =

Пока нет, только пункты выдачи. Для курьера Ozon требует полный адрес получателя — это следующий шаг.

= Поддерживается ли блочный чекаут? =

Нет. Плагин явно объявляет несовместимость с `cart_checkout_blocks` и работает с классическим чекаутом. Совместимость с HPOS заявлена.
